# Cloud Info Chatbot

**Problem 5 – AI Chatbot (Feature Set A)**

A single-page chatbot that answers questions about cloud computing. Users pick a topic, ask a question (or tap a suggested one), and get an AI-generated answer.

## Features

| Feature | Description |
|---|---|
| Topic-based questions | Topic chips (Cloud Basics, AWS, Azure, Google Cloud, Security, Serverless, Cost) with suggested questions for each |
| AI-generated responses | Answers are generated by Claude, focused on the selected topic and streamed in as they are written |
| Conversation display | Chat bubbles for user and bot messages, auto-scrolling, with earlier turns kept for follow-up questions |
| Clear conversation | "Clear" button resets the chat and cancels any reply in progress |

## How to Run

The AI call uses the `sample` runtime capability provided by claude.ai, so the app works when published as a claude.ai Artifact.

1. Open the published Artifact link.
2. Approve the consent prompt on the first question.
3. Choose a topic and start chatting.

Opening the HTML file directly in a browser shows the UI, but AI responses will not work there because the capability is unavailable.

## How It Works

1. `TOPICS` holds each topic and its suggested questions.
2. When a question is sent, it is added to `history` and displayed.
3. A system-style instruction (current topic, short plain-text answer, stay on cloud topics) plus the full history is sent to Claude.
4. The reply streams into a bot bubble and is saved to `history`.
5. Clear empties `history` and re-renders the empty state.

## Customising

- **Add or edit topics:** change the `TOPICS` object at the top of the script.
- **Change answer style or length:** edit the `instructions` string inside `ask()`.
- **Change colours:** edit the CSS variables in `:root` (light and dark themes included).

## Porting to a Standalone App

To run outside claude.ai, replace the `sample(...)` call in `ask()` with a request to your own backend (for example Flask or Node) that calls an LLM API with a server-side API key. Never put the API key in front-end code.

## Limitations

- Conversation history is kept in memory only and is lost on refresh.
- Answers are limited to roughly 150 words by the prompt.
- Requires claude.ai for AI responses.
